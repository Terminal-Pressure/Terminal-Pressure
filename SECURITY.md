# Security Policy

## Supported Versions

Only the latest major release line is supported for security updates.

| Version | Supported |
|---------|-----------|
| 2.x     | ✅        |
| < 2.0   | ❌        |

## Reporting a Vulnerability

Please report vulnerabilities privately by emailing:

- **terminal-pressure@protonmail.com**

Include:

1. A clear description of the issue and impact.
2. Affected version(s) and module(s).
3. Reproduction steps (minimal proof-of-concept preferred).
4. Any suggested mitigation or patch (optional).

### Response Expectations

- Initial acknowledgement target: **within 48 hours**
- Triage target: **within 7 days**
- Fix timeline target:
  - **Critical/High:** 14–30 days
  - **Medium/Low:** best effort based on risk and complexity

We request coordinated disclosure and ask reporters to avoid public disclosure until a fix is available or a coordinated timeline is agreed.
